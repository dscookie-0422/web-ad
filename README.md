# 대출 갈아타기 계산기 (loan-refinance-calculator)

주택담보대출·전세자금대출을 갈아탈 때 **중도상환수수료와 부대비용, LTV까지 넣어**
총 순절감액, 월 납입금 변화, 손익분기점을 계산하는 단일 목적 웹 툴입니다.
**지금 대출과 갈아탈 대출의 상환방식을 각각 골라**(원리금균등·원금균등·만기일시·체증식) 교차 비교할 수 있습니다.
정적 HTML/CSS/JS라서 Cloudflare Pages, Vercel, GitHub Pages 어디든 폴더째 올리면 바로 동작합니다.

## 기능

- **대출 종류**: 주택담보대출 / 전세자금대출 (전세는 만기일시가 기본, LTV 대신 보증금 대비 비율로 표시)
- **상환방식 개별 선택**: 지금 대출과 갈아탈 대출의 방식을 따로 고를 수 있음 (원리금균등 / 원금균등 / 만기일시 / 체증식)
- **체증식**: 체증률(연 %)을 넣으면 첫해 납입금을 낮게 시작해 1년마다 올라가는 스케줄을 계산
- **1년차 · 마지막 해 월 납입금**을 비교표와 ‘월 납입금 흐름’ 차트에 함께 표시
- **집값(보증금) + LTV**: `남은 원금 ÷ 집값 × 100`을 실시간 계산하고, 기준(일반 70% / 규제지역 40% / 생애최초 70·80%) 대비 이내·근접·초과를 배지와 미터로 표시
- **중도상환수수료**: 잔존 개월 ÷ 부과 기간 비율로 계산 (3년 상한 반영)
- **손익분기점 · 누적 순이익 차트 · 결과 요약 복사**
- **예시 프리셋**: 주담대 예시 / 전세대출 예시 / 체증식 비교

## 계산 방식

- **원리금균등**: `월 납입금 = P·i / (1 − (1+i)^−n)`, `i = 연금리/12`
- **원금균등**: 매달 원금 `P/n` + 잔액 이자
- **만기일시**: 매달 이자만, 만기에 원금
- **체증식(연 단위 정률)**: k년차 월 납입금 `= A × (1+g)^(k−1)`.
  `A`는 모든 납입액을 월금리로 할인한 합이 원금과 같아지도록 역산합니다.
  `A = P ÷ Σₖ (1+g)^(k−1) ÷ (1+i)^m` (m은 해당 연차의 월). 마지막 회차는 잔액으로 조정해 **원금 합계 = P, 만기 잔액 = 0원**이 됩니다.
  체증률 0%면 원리금균등과 같은 값이 나옵니다.
  - 검증: 3억 원·연 4%·30년에서 체증률 1/2/3% → 첫해 1,271,947 / 1,123,003 / 985,750원, 마지막 해 1,697,418 / 1,994,279 / 2,322,984원, 총이자 2억 3,093만 / 2억 4,670만 / 2억 6,277만 원 (공개된 국내 체증식 계산기 참조표와 일치).
  - 한국주택금융공사 보금자리론·디딤돌대출의 체증식은 **매월 일정 금액씩** 오르는 방식이라(공식 예시: 1억·연 3%·10년, 첫 달 254,788원 + 매월 12,579원) 첫해·마지막 해 금액이 이 계산기와 조금 다를 수 있습니다. 화면에도 그렇게 안내합니다.
- **중도상환수수료** = `상환원금 × 수수료율 × (잔존일수 ÷ 대출기간)`.
  대출기간이 3년을 넘으면 3년(1,095일)이 분모이므로, 화면에서는 `잔존 개월 ÷ 부과 기간` 비율로 계산합니다.
- **총 순절감액** = (지금 대출 총이자 − 갈아탈 대출 총이자) − (수수료 + 기타 비용)
- **손익분기점** = 월별 이자 차이를 누적해 처음으로 0을 넘는 개월 (수수료를 낸 시점부터 계산)
- **LTV** = `남은 대출 원금 ÷ 집값 × 100`. 기준 비율(2026년 11월): 규제지역 무주택 40%, 수도권 비규제·지방 70%, 생애최초 수도권·규제지역 70%, 지방 80%. 전세대출은 LTV 대신 보증금 대비 비율(80% 기준)로 표시합니다.

같은 원금·같은 남은 기간으로 비교하고, 상환방식은 각각 따로 계산합니다.

## 검증

`test/e2e.py`가 실제 Chromium에서 **184개 항목**을 확인합니다
(체증식 스케줄 10가지 조합의 원금 합계·만기 잔액·총이자, 공개 참조표 대조, 기존 원리금균등 vs 신규 체증식 교차 비교,
집값/LTV 계산과 배지 상태, og-image.png 크기·연결, 화면 표시, 차트 2종, 복사, 모바일·PC 레이아웃, 접근성, sitemap, 외부 요청 0건).

```bash
cd projects/loan-refinance-calculator
python3 -m http.server 8765 &
LD_LIBRARY_PATH=/workspace/.cache/chromelibs/usr/lib/x86_64-linux-gnu \
PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright python3 test/e2e.py
# 마지막 줄: 총 184개 검사 · 성공 184 · 실패 0
```

공유 이미지를 다시 만들 때:

```bash
LD_LIBRARY_PATH=/workspace/.cache/chromelibs/usr/lib/x86_64-linux-gnu \
PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright python3 test/make_og.py
# 저장: og-image.png (1200×630)
```

> 이 작업 환경의 브라우저 도구는 `127.0.0.1` 같은 loopback 주소를 막고 있어서,
> 로컬 서버 검증은 Playwright + Chromium(headless)으로 진행했습니다.
> 필요한 브라우저는 `/workspace/.cache/ms-playwright`에 설치되어 있습니다.
> 다른 환경에서는 `pip install playwright && playwright install chromium` 후 같은 방식으로 실행하면 됩니다.
